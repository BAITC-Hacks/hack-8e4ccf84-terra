## Блокеры и следующий шаг

| ID | Неизвестное / проблема | Что блокирует | Конкретное действие |
|---|---|---|---|

| B02 | Начало/конец/мгновенная метка; способ усреднения мощности | Часовые цели и интервал доступности | Получить спецификацию SCADA: период, timestamp convention, aggregation |

| B04 | Нормализация, номинал, общий/разный знаменатель | МВт/МВт·ч и агрегацию между объектами | Получить формулу, параметры и единицы; до этого исходная шкала отдельно |
| B05 | Февральский факт отсутствует вопреки именам файлов | Численные метрики февраля и полноту оценки | Получить отдельный разрешённый evaluation-only файл; не достраивать факт |
| B06 | Задержка доступности измерений и расписание выпусков | Честный снимок as-of | Согласовать available_at и часы выпуска, версионировать допущения |
| B07 | Архивные прогоны погоды отсутствуют в resources | Погодные признаки backtest | S03 проверяет отдельный источник, поля, высоты, горизонт и публикацию |

Координаты численно установлены по ссылкам; остаётся подтверждение mapping пользователем по FR-01. Пропуски не блокируют парсинг, но требуют отчёта покрытия и правила исключения. S01 может проектировать raw-хранилище и явные неизвестные поля; отсутствие B01–B04 нельзя маскировать дефолтами и считать gate финального прогноза пройденным.

Правило февраля полностью описано в контракте: только оценка, без обучения/подбора/лагов до отдельного разрешения; фактическая будущая погода тоже не прогнозный вход. Это документированная политика, исполнение которой ещё предстоит реализовать и проверить в зависимых slices.

## Воспроизведение проверки без изменения данных

Запустить из корня worktree: `python -` и передать следующий код через stdin (в PowerShell — here-string). Используется только стандартная библиотека; код не записывает файлы. Проверка завершается ошибкой при несовпадении ключевых фактов с этим аудитом.

```python
import csv, hashlib, math
from collections import Counter
from datetime import datetime, timedelta
from pathlib import Path

expected = [
    (142360, "c4c341582fb2dd348b7187f0128cff265fe055f469413871ebb5db50eef58b5b", 9992, 67, 23667, 96),
    (149499, "820578cd18bb557cd30c2e102f3ae5a386dfc6c489a5a15743339c2b017305e5", 2853, 178, 24785, 219),
]
files = sorted(Path("resources").glob("*.csv"))
assert len(files) == 2
series = []
for path, (n, sha, missing, gaps, full, partial) in zip(files, expected):
    raw = path.read_bytes()
    assert hashlib.sha256(raw).hexdigest() == sha
    assert not raw.startswith(bytes([239, 187, 191]))
    header, *rows = list(csv.reader(raw.decode("utf-8").splitlines()))
    assert len(header) == 5 and len(rows) == n
    assert all(len(r) == 5 and all(v.strip() for v in r) for r in rows)
    assert all(int(r[0]) == i + 1 for i, r in enumerate(rows))
    ts = [datetime.strptime(r[1], "%Y-%m-%d %H:%M:%S") for r in rows]
    assert ts[0] == datetime(2023, 3, 11) and ts[-1] == datetime(2026, 1, 31, 23, 50)
    assert len(set(ts)) == n and all(a < b for a, b in zip(ts, ts[1:]))
    assert all(t.minute % 10 == 0 and t.second == 0 for t in ts)
    assert int((ts[-1] - ts[0]).total_seconds() / 600) + 1 - n == missing
    assert sum(b-a > timedelta(minutes=10) for a, b in zip(ts, ts[1:])) == gaps
    counts = Counter(t.replace(minute=0, second=0) for t in ts)
    assert sum(v == 6 for v in counts.values()) == full
    assert sum(v < 6 for v in counts.values()) == partial
    assert not any(datetime(2026, 2, 1) <= t < datetime(2026, 3, 1) for t in ts)
    values = [[float(r[i]) for r in rows] for i in (2, 3, 4)]
    assert all(math.isfinite(v) for vs in values for v in vs)
    assert min(values[1]) == 0 and max(values[1]) == 1
    print(path.name, n, sha, [(min(v), max(v)) for v in values])
    series.append(dict(zip(ts, (r[3] for r in rows))))
a, b = series
common = a.keys() & b.keys()
assert len(common) == 141357
assert sum(a[t] == b[t] for t in common) == 42894
print("PASS: source hashes, structure, time grid, coverage, February isolation inventory")
```

Проверка относится к входным файлам, а не к реализованной защите от утечки. Отдельно: `git diff --exit-code origin/main -- resources` подтверждает отсутствие изменений датасета относительно базы. Lint/build и результаты push фиксируются в `STATE.md`.

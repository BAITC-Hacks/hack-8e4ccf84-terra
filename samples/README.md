# Синтетический набор

`history.csv`: 48 часовых строк одного вымышленного объекта `demo-line`, 30–31 января 2026 UTC. Значения сгенерированы для проверки импорта, не взяты из материалов организаторов. CC0-1.0: разрешены копирование, изменение и распространение без условий. Метаданные и SHA-256 — в `manifest.json`.

Мощность безразмерная; это не МВт, не энергия и не две турбины. Метка — начало часового интервала. Объект должен быть явно создан перед импортом. Mapping задаётся пользователем по заголовкам CSV. Повторный импорт того же файла проверяет идемпотентность. Для негативных проверок используйте копию: удалите значение, повторите строку, задайте несовместимые единицы в mapping.

48 строк недостаточно для временной валидации 3/6/12 месяцев и февральского бэктеста. Погодного архива здесь нет; придумывать его происхождение или выдавать синтетические метрики за качество модели нельзя. Распространение исходных `resources/` требует отдельного подтверждения условий организатора; S09 не копирует их в демонабор.
